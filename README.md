## 🛠️ Facilitation Method

All modules use **3-Slide Pulse Check**: EXPLAIN (2-3m) → DEMO (1m) → PULSE CHECK 🟢🟡🔴 → YOU TRY IT (2-4m) → DEBRIEF → TRANSITION

Never >15 min one-way lecture.
